# 🔥 Heat Diffusion Simulator App

**An Interactive, High-Performance Heat Transfer Visualization Tool**

Welcome to the Heat Diffusion Simulator! This is not just a webpage—it is a fully-fledged, API-driven web application designed to simulate and visualize 2D heat diffusion in real-time. Built with a robust Python backend and a responsive, Apple-inspired HTML/JS frontend canvas, this tool allows users to engineer custom materials, define thermal parameters, and watch thermodynamics in action.

## 🚀 Key Features

*   **Custom Material Design Engine:** An interactive canvas where users can draw bounding boxes and ellipses, assigning specific thermal diffusivity properties to create composite materials.
*   **Real-time Thermodynamic Simulation:** Implements a stable numerical solver for the 2D heat equation, processing boundary temperatures, initial conditions, and varying diffusivity maps.
*   **Dynamic Visualizer & Playback:** Renders the simulation frame-by-frame with a high-fidelity color map (black → red → yellow). Includes full playback controls (play, pause, scrub) for deep analytical review.
*   **RESTful API Architecture:** Clean decoupling of the frontend interface from the heavy-lifting Python simulation engine via a well-documented API.

## 🛠️ Technical Stack
*   **Backend:** Python 3.8+, Flask, NumPy (for matrix-based numerical methods)
*   **Frontend:** Vanilla JavaScript, HTML5 Canvas, CSS3
*   **Architecture:** Async background task processing for simulations to prevent UI blocking.
